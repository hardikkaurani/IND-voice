# Design System: Mercury Dark

## Overview
Mercury Dark is a refined dark fintech design system tailored for high-trust business ledger workflows. It combines a deep charcoal canvas (`#171721`) with luminous electric blue interactive elements (`#5266EB`), soft typography, and flat, atmospheric depth.

## Color Tokens
* **Canvas / Neutral:** `#171721`
* **Surface Containers:** `#20202D`
* **Surface Hover:** `#282838`
* **Primary Accent:** `#5266EB`
* **Primary Strong (Hover):** `#4055E6`
* **Border:** `#374151`
* **Text / Secondary:** `#EDEDF3`
* **Muted / Tertiary:** `#70707D`
* **Debit / Error / Udhaar:** `#EF4444`
* **Credit / Success / Jama:** `#10B981`

## Component Guidelines
* **Buttons:** Compact 40px height, fully rounded pill radius (`rounded-full`), electric blue background.
* **Cards & Panels:** 8px to 16px radius (`rounded-xl` to `rounded-2xl`), subtle 1px border (`#374151`), shadowless flat elevation.
* **Typography:** Clean neo-grotesque font stacks with crisp contrast and generous line height for numbers and monetary amounts.
* **Audio Feedback:** Real-time waveform visualization with pulsing blue and red states.
